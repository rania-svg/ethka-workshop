# ورشة إذكاء · صناعة القيمة بالذكاء الاصطناعيّ

عرض الورشة (يومان، ٦٠ شريحة) لمهارات استعمال الذكاء الاصطناعيّ في الإدارات القانونيّة.

## التشغيل

افتح `index.html` في متصفّح حديث (Chrome أو Edge أو Safari)، مع بقاء مجلّد `fonts` بجانبه.

- التنقّل: الأسهم أو المسطرة أو النقر على الشريحة.
- ملاحظات المقدّم: زرّ «ملاحظات المقدّم» أو حرف N.
- ملء الشاشة: زرّ «ملء الشاشة».
- القفز إلى بداية اليوم الأوّل أو الثاني: زرّا «اليوم ١» و«اليوم ٢».

## الملفّات

- `index.html`: العرض كاملًا في ملفّ واحد.
- `fonts/`: خطوط ثمانية المستعملة في العرض.
